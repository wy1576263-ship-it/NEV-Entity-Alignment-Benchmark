# NEV Knowledge Graph & Entity Alignment Benchmark

This repository contains the dataset, knowledge graph construction scripts, and the evaluation benchmark for the **Weighted Fusion Entity Alignment** strategy described in our paper. 

Our research focuses on resolving entity redundancy caused by domain-specific synonyms and colloquial abbreviations in the New Energy Vehicle (NEV) domain.

> **💡 System Interface Demonstration:** Beyond the algorithmic evaluation, we have developed a complete Neo4j-based full-stack QA prototype for the NEV domain. Please refer to the Figures in our manuscript for the detailed visual demonstrations of the system interface (including the data dashboard and D3.js knowledge graph visualization). The frontend HTML/JS source code is tightly coupled with our internal proprietary database and is omitted here to maintain algorithmic focus.

---

## 🔐 Data Availability & NDA Compliance Statement

This research is conducted using real-world diagnostic records from our industry partners. To strictly comply with the **Non-Disclosure Agreement (NDA)** and data privacy regulations, the following restrictions apply to this open-source repository:

* **Proprietary Models & Raw Corpus:** The full 150,000 raw QA diagnostic corpus and the fine-tuned proprietary deep learning model weights are highly confidential corporate assets and **cannot be distributed**.
* **Knowledge Graph Topology:** We release the core topological data (`New_Ontology_Nodes.csv` and `New_Ontology_Edges.csv` with ~14k edges) and raw vehicle parameters (`Vehicle_Parameters.csv`) to demonstrate the industrial scale and architectural validity of the NEV Knowledge Graph.
* **Desensitized Academic Benchmark:** To ensure scientific reproducibility of our alignment algorithm without compromising sensitive data, we provide a rigorously desensitized subset of 200 confusing entity pairs (`confusing_entities_200.csv`) along with their corresponding semantic inference logits (`bert_output_logits.csv`) generated by our private model.

## ⚙️ Environment Requirements

* **Python:** 3.8+
* **Hardware:** Hardware: Tested on Intel i7-11850H. (Note: The initial deep learning model fine-tuning was performed on a GPU server. This repository provides the CPU-based deployment and lightweight reproduction environment, so no GPU is required to run the scripts).
* **Dependencies:** Install the required packages using the following command:

    pip install -r requirements.txt

*(Dependencies include `pandas`, `neo4j`, `numpy`, and `scikit-learn`)*

## 🚀 Quick Start: Reproducing Table 1

Reviewers and researchers can transparently verify our 0.7/0.3 weighted fusion algorithm and exactly reproduce the ablation results reported in the manuscript using the provided inference logits. 

Run the evaluation script from the root directory:

    python Scripts/reproduce_table_1.py

**Expected Output:**
The script will load the saved model logits, apply the weighted formula ($S(A, B) = 0.7 \times S_{Dice}(A, B) + 0.3 \times S_{cos}(A, B)$), and output the exact evaluation scores (e.g., **92.0% Fusion Accuracy**) reported in **Table 1** of our manuscript.
